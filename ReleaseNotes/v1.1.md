## English

### Features
- Added a bootstrap scene and an initial logo screen
- Disabled the screen settings dropdowns in the WebGL build
- Changed the ending scene to return to the opening scene
- Added colors to fixed stat values in card, item, and potion text

### Bug Fixes
- Fixed an issue where the defeat message briefly appeared on victory
- Fixed an issue where used cards didn't move to the graveyard
- Fixed an issue where 'Freeze' (enemy skill) didn't work
- Fixed an issue where the deck was refilled with all 12 cards when it ran out, even while cards were in hand
- Fixed an issue where tooltips and card stat text didn't update when a character holding an item died
- Fixed an issue where card stats were displayed abnormally

## 한국어

### 기능
- 부트스트랩 및 초기 로고 화면 추가
- WebGL 빌드에서 화면 설정 드롭다운 비활성화
- 엔딩 씬에서 오프닝 씬으로 이동하도록 수정
- 고정값 성능을 가진 카드/아이템/포션 수치 텍스트에 색 추가

- 승리 시 패배 메시지가 잠시 뜨던 문제 수정
- 사용한 카드가 묘지로 이동하지 못하던 문제 수정
- Freeze 안 되던 문제 수정
- 덱을 다 사용했을 때, 패에 카드가 있어도 덱을 12장으로 시작하던 문제 수정
- 아이템을 가지고 있는 캐릭터가 죽었을 때, 툴팁과 카드 수치 텍스트 업데이트 안 되던 문제 수정
- 카드 수치가 비정상적으로 표시되던 문제 수정
